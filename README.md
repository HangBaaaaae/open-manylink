# OpenManyLink (오픈매니링크)

**오픈소스 인스타그램 댓글 → 자동 DM 발송 & 링크 클릭 트래킹 플랫폼**입니다.  
Meta 공식 무료 **Instagram Graph API v21.0** 규격을 준수하며, **Docker나 복잡한 서버 설정 없이** Node.js(`npm run dev`) 또는 Vercel 등으로 누구나 무료로 바로 실행·배포할 수 있습니다.

---

## 주요 기능

1. **특정 게시물·키워드 댓글에 자동 DM 발송**
   - 정확 일치, 단어 포함, **초성·공백무시 매칭**(`"ㅇㅇ"`, `"ㅇ ㅇ 신청"`, `"ㄱㄱ"`, `"공구"` 등) 지원
   - 전체 게시물 상시 감지(`ALL`) 또는 특정 릴스/피드 지정 가능
2. **팔로우 여부 확인 뒤 발송 (Meta 공식 2-Step 검증)**
   - 댓글 감지 시 1차 DM으로 `[✅ 팔로우 확인하고 링크 받기]` 버튼 카드 발송
   - 버튼 클릭(또는 답장) 시 `GET /{IGSID}?fields=is_user_follow_business` API를 실시간 조회해 팔로워에게만 최종 혜택 링크 오픈
3. **DM 링크 버튼 넣기 + 클릭 수 실시간 확인**
   - 단일 버튼 카드(최대 3개 버튼) 및 슬라이드형 멀티 카드 캐러셀 지원
   - 자체 단축 URL(`/r/[code]`) 리다이렉트(HTTP 307)를 통해 클릭 수 카운트 및 `utm_source=instagram_dm` 자동 부착
4. **댓글 자동 답글 달기 (스팸 차단 방지용 랜덤 로테이션)**
   - 다중 대댓글 프리셋을 등록해 무작위 순환 응답
5. **여러 인스타 계정 통합 관리 & 하이브리드 실시간 감지**
   - `IGAA...` 토큰, 통합 로그인 시스템 사용자 토큰(`EAA...` + Instagram 비즈니스 계정 ID), **인스타그램 OAuth 2.0 원클릭 로그인** 모두 지원
   - 별도 외부 Webhook 서버 설정 전에도 **6초 주기 하이브리드 동기화(`/api/meta/sync-comments`)**로 로컬 PC에서 즉시 실제 댓글 감지·대댓글·DM 발송 작동

## 빠른 시작 (로컬 실행)

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

### 자동 검증 테스트 실행 (`npm test`)

서버가 실행 중인 상태에서 아래 명령어를 실행하면 보안(토큰 마스킹), Meta Webhook 인증, 키워드 매칭, 2단계 팔로우 검증, 단축링크 307 리다이렉트까지 8단계 통합 테스트를 자동 검증합니다.

```bash
npm test
```

## 프로덕션 실행 및 배포 (Docker 불필요)

Docker 설치 없이 일반 Node.js 환경이나 Vercel/클라우드에서 바로 빌드·실행할 수 있습니다.

```bash
npm run build

```

## Meta 무료 API 연동 가이드

1. **인스타그램 프로페셔널 전환**: 인스타그램 앱에서 계정을 크리에이터 또는 비즈니스로 전환하고, `[설정 → 메시지 및 스토리 답장 → 메시지 제어 → 연결된 도구 액세스 허용]`을 켭니다.
2. **Meta 앱 생성 및 무료 토큰 발급**:
   - [Meta for Developers](https://developers.facebook.com/apps)에서 비즈니스 앱을 생성하고 `Instagram` 제품을 추가합니다.
   - **[방법 A — 토큰 직접 입력]**: `API 설정`에서 생성된 액세스 토큰(`IGAA...` 또는 통합 로그인 `EAA...`)과 `@아이디` 옆의 **숫자 ID(Instagram 비즈니스 계정 ID)**를 대시보드의 `[+ 인스타 계정 연결]` 모달에 입력합니다.
   - **[방법 B — 다계정 인스타 로그인(OAuth)]**: `앱 구성`에 리디렉션 URL(`http://localhost:3000/api/auth/instagram/callback`)을 등록하고 `.env`에 `INSTAGRAM_APP_ID`, `INSTAGRAM_APP_SECRET`을 설정하면 아이디/비번 로그인만으로 여러 계정을 즉시 추가할 수 있습니다.
3. **자주 묻는 질문 (FAQ)**:
   - **Q. 대댓글은 달렸는데 상대방 계정에서 DM이 안 보여요!**
     - 인스타그램 정책상 **버튼이 포함된 템플릿 DM(`generic_template`)은 PC 웹 브라우저에서는 표시되지 않으며 스마트폰 '인스타그램 모바일 앱'**에서만 보입니다.
     - 또한 처음 DM을 보내는 상대방에게는 일반 채팅방이 아닌 **`인스타 앱 DM 우측 상단 → [요청(메시지 요청함)]`** 탭으로 들어가므로 해당 탭을 확인해주세요.
